RESET 90 v1 — free phone-installable PWA

1. Unzip this folder.
2. Create a FREE GitHub account (if needed) and a PUBLIC repository named reset90.
3. Upload index.html, manifest.json, sw.js, icon.svg, icon-192.png, icon-512.png to the repository ROOT. Never upload exported personal data or backup files.
4. In repository Settings > Pages, choose Deploy from a branch, main, / (root), Save.
5. Once published, open https://YOUR-USERNAME.github.io/reset90/ in Chrome on your Galaxy.
6. Chrome menu (three dots) > Add to Home screen > Install (wording may vary).
7. Use the app. Data is saved ONLY in that browser's local storage on that phone. Export a JSON backup regularly (Settings). Avoid clearing browser site data; doing so may erase entries.

The public GitHub repo contains only app code, not your locally stored records. The site URL is public, but your entered data is not automatically uploaded. This is not encrypted storage or a substitute for clinical record systems. Don't record confidential medical details.

This first version uses browser localStorage for convenience and is best suited to one device. No cloud sync, accounts, or automatic backup. If you open the app on another device, its data will be separate until you import a backup.
